# Expense Tracker API

**Что это и для кого:**
Это учебный REST API сервис для учёта личных расходов. Приложение позволяет добавлять новые траты, просматривать их списком, фильтровать по категориям, искать конкретную запись по ID и удалять ненужные. 
Сервис предназначен для разработчиков, которые хотят интегрировать учёт расходов в свои приложения (например, в Telegram-бота или мобильный клиент), или для всех, кто хочет вести простую статистику трат.

## Установка и настройка окружения

1. Клонируйте репозиторий на свой компьютер:
   
   git clone https://github.com/dashty163/expense-tracker.git
   cd project
   

2. Создайте и активируйте виртуальное окружение:
   - **Windows:**
     
     python -m venv .venv
     .venv\Scripts\activate
     
   - **Linux / macOS:**
     
     python3 -m venv .venv
     source .venv/bin/activate
    

3. Установите необходимые зависимости:
   
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   

## Запуск приложения

Для запуска в режиме разработки (с автоматической перезагрузкой при изменении кода) используйте команду:

uvicorn app_final:app --reload


После запуска приложение будет доступно по адресу:
- Главная страница: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Интерактивная документация (Swagger UI):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

**Запуск без `--reload` (для обычной работы приложения):**
Для стабильной работы (например, на сервере) флаг `--reload` не используется, так как он создает лишнюю нагрузку:

uvicorn app_final:app --host 0.0.0.0 --port 8000

## Запуск тестов

В проекте настроены автоматические тесты, которые проверяют работоспособность API. Чтобы запустить их, выполните:

python -m pytest -v


## Переменные окружения

Приложение использует переменные окружения для гибкой настройки. Для работы создайте файл `.env` в корне проекта (пример есть в файле `.env.example`):
- `APP_NAME` — название приложения (по умолчанию: "Expense Tracker").

## Диагностика (Health Check) и Логирование

**Как проверить работу:**
- Проверка статуса (Health Check): `curl http://127.0.0.1:8000/health` (должен вернуть `{"status":"ok"}`)
- Проверка версии: `curl http://127.0.0.1:8000/version` (должен вернуть `{"version":"0.1.0"}`)
- Или просто откройте эти адреса в браузере.

**Где смотреть логи:**
Все основные события (запуск, запросы к API, добавление/удаление расходов) и ошибки логируются. Логи выводятся в стандартный поток вывода (stdout), то есть **прямо в консоль терминала**, где запущен сервер `uvicorn`. 
Формат логов: `YYYY-MM-DD HH:MM:SS,ms - LEVEL - Message`.
